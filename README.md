## 📖 Overview

The **Visa & Travel Requirements Checker** provides instant, reliable travel intelligence for international passengers. Rather than searching across scattered government embassy portals, travelers can input their citizenship and destination to get verified entry criteria.

- 🛂 **Visa Status Breakdown** - Instant eligibility: Visa-Free, VoA (Visa on Arrival), eVisa, or Embassy Visa required.
- ⏳ **Passport Validity Guard** - Flags rules such as the 6-month validity standard and minimum blank page rules.
- 💉 **Health & Vaccine Protocols** - Advisories on Yellow Fever cards, mandatory vaccines, and travel health notes.
- 📋 **Customs & Currency Limits** - Details duty-free allowances, cash declaration thresholds, and prohibited items.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.x or higher)
- npm (v9.x or higher)

### Installation & Run

1. **Clone the repository:**
   ``bash
   git clone [https://github.com/Harry-aura/Visa-Travel-Requirements-Checker.git](https://github.com/Harry-aura/Visa-Travel-Requirements-Checker.git)
   cd Visa-Travel-Requirements-Checker
   ``n
2. **Install dependencies:**
   ``bash
   npm install
   ``n
3. **Start the development server:**
   ``bash
   npm run dev
   ``n
